# PerfomAC — App de Performance Pessoal

## Design
- Dark theme: background `#0f0f1a` (hsl 240 15% 7%), primary purple `hsl(262 83% 58%)`
- Neon glow effects (`.neon-glow`, `.neon-text` classes)
- Interface 100% em português (pt-BR)
- Responsive: sidebar no desktop, bottom nav + hamburger no mobile

## Estrutura de Páginas (todas dentro de `(app)/` layout protegido)
- `/home` — tarefas + lembretes
- `/estudos` — sessões de estudo, timer pomodoro, upload de arquivos (S3)
- `/treinos` — CRUD de treinos com exercícios
- `/alimentacao` — CRUD de refeições com itens
- `/metas` — CRUD de metas com progresso, opção público/privado
- `/conta` — perfil, amizades (enviar/aceitar/recusar)

## Funcionalidades
- IA chat flutuante (componente `AIChat`) em todas as páginas logadas, streaming via `/api/ai` (model: gpt-5.4-mini)
- Sistema de amizades bilateral (Friendship model: pending → accepted/rejected)
- Upload de arquivos via presigned URLs (S3)
- Auth: email+senha, sem confirmação no signup, JWT strategy

## Modelos Prisma
User, Account, Session, VerificationToken, Task, Reminder, StudySession, UploadedFile, Workout, Exercise, Meal, MealItem, Goal, GoalProgress, Friendship

## Preferências do Usuário
- Dados privados por usuário (cada um vê só os seus)
- Metas podem ser marcadas como públicas para amigos
- Sem código de confirmação no cadastro; apenas para troca de senha (não implementado ainda)
